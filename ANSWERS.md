# Відповіді

1. **Які системні виклики стоять за функціями Python у вашій задачі?**

   - Використовуються `fork()` (створення нових процесів через `os.fork()`), `wait4`/`waitpid()` (очікування завершення дочірнього процесу через `os.waitpid()`) та `getppid()` (отримання ідентифікатора батьківського процесу через `os.getppid()`).

2. **Що ви побачили в strace для свого сценарію?**

   - Під час трасування процесів за допомогою `strace` видно системний виклик клонування (`clone`/`fork`), швидке завершення дочірнього процесу (`exit_group`), а також те, як онуки продовжують виконання та змінюють свого батька (PPID змінюється на системний процес ініціалізації `init`/`systemd`).

3. **Які граничні випадки ви перевірили й що повертає ваша функція в найпростішому з них?**

   - У файлі `tests/test_my.py` перевірено випадок із нульовою кількістю онуків (`n = 0`) та зі стандартною кількістю онуків (`n = 3`). У найпростішому випадку (`n = 0`) функція успішно створює процес-посередник, дочікується його завершення без зависань і повертає код завершення `0`.
